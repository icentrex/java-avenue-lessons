## mentor1


Программа для учёта выданной техники пользователям

Примерный план работы программы

```cmd
Начальное меню:
1 - Меню "Пользователи"
2 - Меню "Техника"
0 - Выход из программы

При выборе 1 - Меню "Пользователи":
  Вывести список созданных пользователей
  Доступные команды
  1 - Создать пользователя
  2 - Выбрать пользователя
  9 - Назад в главное меню
  0 - Выход из программы
  
    При выборе 1 - Создать пользователя:
    Заполнить необходимые поля, создать пользователя. Выбрать пользователя (как при варианте 2)
  
    При выборе 2 - Выбрать пользователя:
    Информация о пользователе + закреплённая за ним технгика
    Команды
    1 - Закрепить технику (Вывести список доступной техники с id)
    2 - Открепить технику
    3 - Изменить пользователя
    4 - Удалить пользователя (Ошибка если есть закреплённая техника)
    9 - Назад в главное меню
    0 - Выход из программы
  
При выборе 2 - Меню "Техника":
  Вывести список доступной техники
  Доступные команды
  1 - Добавить технику
  2 - Выбрать технику
  9 - Назад в главное меню
  0 - Выход из программы
  
    При выборе 1 - Добавить технику:
    Заполнить необходимые поля, создать технику. Выбрать технику (как при варианте 2)
    
    При выборе 2 - Выбрать технику:
    Информация о технике + пользователь за кем техника закреплена
    Команды
    1 - Изменить технику
    2 - Закрепить технику (Вывести список пользователей с id)
    3 - Открепить технику
    4 - Удалить технику (Ошибка если техника закреплена)

```


Service работает с объектами / собирает готовые объекты - Техника с композицей (привязанным) пользователем. 
Или пользователь со списком (List) своей связанной техники/ или устанавливает связь техники с пользователем 
Например метод который на входе получает Технику и Пользователя которого кк ней нужно прикрепить
